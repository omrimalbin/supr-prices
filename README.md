# מחירי סופר לפי עיר

שואב כל 6 שעות את קובצי המחירים שהרשתות מפרסמות לפי חוק המזון, לערים שב-`cities.txt`, ומפרסם עמוד השוואה ב-GitHub Pages.

- הוספת עיר: Actions → עדכון מחירים → Run workflow → שם העיר.
- ההורדה מהרשתות: [il-supermarket-scraper](https://github.com/OpenIsraeliSupermarkets/israeli-supermarket-scarpers).
- 7 רשתות חוסמות גישה מחוץ לישראל ולכן לא נכללות (חצי חינם, ויקטורי, מחסני השוק, יינות ביתן/קרפור, נתיב החסד, ח. כהן, סופר-פארם).
